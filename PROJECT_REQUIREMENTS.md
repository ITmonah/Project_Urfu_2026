# Требования к итоговому проекту

Основано на файле `proj.pdf`.

## Обязательные требования

1. Исходные коды проекта должны находиться в репозитории GitHub или GitVerse.
2. В проекте должна использоваться предварительно обученная модель или LLM.
3. Разработка возможностей приложения должна проводиться в отдельных ветках.
4. При слиянии ветки в основной репозиторий должно выполняться Code Review.
5. Код приложения должен соответствовать стилю PEP8.
6. Приложение должно содержать тесты.
7. Необходимо разработать Docker image приложения и выложить его на Docker Hub.
8. В репозитории должны быть настроены процессы CI.
9. CI должен включать unit tests, проверку PEP8, сборку Docker image и публикацию в Docker Hub.
10. В репозитории должна быть оформлена документация приложения.

## Как проект закрывает требования

- Web/API приложение реализовано на FastAPI в `fastapi_app`.
- Предобученные `.pt` и `.pth` веса загружаются из отдельного репозитория `likip3/AI-Models`.
- Unit tests находятся в `tests`.
- PEP8/runtime-проверка выполняется через `ruff`.
- Docker image собирается из `Dockerfile`.
- CI/CD настроен в `.github/workflows/ci.yml`.
- Инструкции по запуску, Docker и модельным весам описаны в `README.md`.
